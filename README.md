# tomo

note運営の日々の振り返りをMarkdownで記録するリポジトリです。

## 使い方

1. `templates/note-daily-template.md` を使って、その日の振り返りを記入します。
2. 記入内容をChatGPTに送ります。
3. 内容を `daily-reviews/YYYY-MM-DD.md` の形式で保存します。

## フォルダ構成

- `templates/` — 記入用テンプレート
- `daily-reviews/` — 日付ごとの振り返り記録

## ファイル名のルール

振り返りは `daily-reviews/YYYY-MM-DD.md` とします。同じ日付のファイルがすでに存在する場合、上書きする前に追記・更新の確認を行います。
